# Churn Risk Modeling 

Проект по прогнозированию оттока клиентов телекоммуникационной компании с оценкой бизнес-эффекта и интерпретацией моделей машинного обучения.

## Стек технологий
* **Python**, **Pandas**, **NumPy**
* **Scikit-learn** (моделирование, пайплайны)
* **Matplotlib**, **Seaborn** (разведочный анализ данных / EDA)
* **Jupyter Notebook**

## Структура проекта
* `notebooks/` — разведочный анализ данных и эксперименты с моделями.
* `requirements.txt` — зависимости проекта.
